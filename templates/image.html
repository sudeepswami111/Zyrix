CNN Architecture used for this classifier

Input
32x32x3 → Conv2D
32 filters → MaxPool
16x16 → Conv2D
64 filters → MaxPool
8x8 → Flatten
4096 vals → Dense
64 neurons → Output
Sigmoid
Conv2D slides small 3x3 filters across the image, learning to detect edges, shapes, and textures. MaxPooling halves the spatial size, making the network faster and more robust to small position shifts. Sigmoid outputs a number between 0 and 1: closer to 1 = Automobile, closer to 0 = Airplane.
